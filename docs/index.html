Honest QR Code API

A deterministic, privacy-safe QR renderer you can run as a binary, container, Lambda function, or library. The application does not log request bodies or QR payloads.

OpenAPI 3.1 specification · Source code · Free browser generator

Private POST request

curl -X POST http://localhost:8080/v1/qr \
  -H "content-type: application/json" \
  --output wifi.svg \
  -d '{
    "data": {
      "kind": "wifi",
      "ssid": "My Network",
      "password": "secret",
      "security": "wpa"
    },
    "render": {
      "format": "svg",
      "width": 512,
      "error_correction": "medium"
    }
  }'

Simple image URL

<img src="https://api.example.com/v1/qr?data=https%3A%2F%2Fexample.com&format=svg" alt="QR code">

Query strings can appear in proxy and access logs. Use POST for WiFi passwords, contact cards, private links, or any sensitive value.

Operational endpoints

  • /healthz — process liveness
  • /readyz — real renderer readiness check
  • /metrics — OpenMetrics counters and render latency
  • /v1/batch — deterministic ZIP archive with a JSON manifest
